# SMAT Auction — Premium Visual Redesign

Frontend-only redesign inspired by the supplied IPL auction references. Includes a near-black/charcoal palette, amber-orange accents, updated cards and controls, a cricket-ball brand mark, timer progress bar, franchise initials avatars, activity event styling and responsive desktop/mobile layouts.

Existing element IDs, data-action attributes, API routes, auction rules, bidding validation, timer deadlines, database models, authentication and WebSocket protocol are preserved. JavaScript additions are presentation-only. The other requested workflow changes are deliberately not included.

For deployment, this ZIP is a complete source snapshot. To preserve later backend changes, copy only app/static/index.html, app/static/style.css and app/static/app.js, retaining app/static/fonts from this package. Hard-refresh browsers after deployment.
